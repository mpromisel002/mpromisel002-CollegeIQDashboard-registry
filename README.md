# College Fit Advisor — weekly data file

`snapshot.json.gz` is read by the College Fit Advisor desktop app at startup so searches take
seconds. It is rebuilt every week from the official sources the app otherwise reads live:
IPEDS (Urban Institute Education Data Portal), the U.S. Department of Education College
Scorecard, and each listed school's own Common Data Set. Each value keeps its source and year.

This branch is replaced on every build and holds one commit. Do not edit it.
